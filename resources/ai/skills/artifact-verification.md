# Artifact Verification Skill

For downloaded or generated artifacts:

- Record full path.
- Record byte size.
- Record SHA-256 when available.
- Identify source URL or producing command.
- Verify signature/checksum when vendor provides one.
- Flag unofficial mirrors or repackaged files.
