# Package Selection Skill

When mapping product names to packages:

- Search by product name.
- Prefer exact vendor/product package IDs.
- Avoid unofficial or low-confidence packages unless clearly marked.
- Check version and publisher hints.
- If multiple candidates exist, explain best candidate and ask when risk matters.
