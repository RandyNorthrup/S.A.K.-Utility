# Reviewed test skips.
#
# One line per test function that called QSKIP, in the form
#   <test_binary>::<TestClass::testFunction> = why this skip is acceptable
#
# scripts/check_test_skips.ps1 fails when a skip appears that is not listed
# here AND when a line here did not skip on the last run. Regenerate with
# -UpdateBaseline, then replace every NEEDS-REASON with a real reason;
# the check rejects the marker, so the file cannot become a rubber stamp.
#
# A skip is only acceptable when the thing it needs genuinely cannot exist on
# a build machine. "Hard to set up" is not a reason - it is a fixture to write.
#
# Re-measured after filesystem/adapter host-state closure: 5094 test functions passed and 28
# skipped, so 0.55 percent of what the suite could execute did not execute.
# Wave 26 removed seven dormant host-conditional sites. None was an observed row in this
# latest-run baseline, so its 28 runtime rows stay unchanged until the next complete suite audit.
# That number is the point of this file. ctest reports a binary as Passed when
# every one of its functions skipped, so without this the suite can report
# 222/222 while a subsystem quietly stops being exercised.
#
# The four groups below are ordered by how defensible they are. Group D is the
# one that should shrink.

# ---------------------------------------------------------------------------

#

# machine would destroy it. The env var IS the safety interlock, so these skips
# are correct behaviour and must never be "fixed" by defaulting them on.
# ---------------------------------------------------------------------------
